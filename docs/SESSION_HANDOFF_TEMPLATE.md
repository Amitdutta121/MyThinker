# Session Handoff Template

Use this structure at the end of each implementation session.

## Completed

- milestone or slice completed,
- files changed,
- tests added or updated,
- commands run.

## Decisions locked

- interfaces finalized,
- prompt versions added or changed,
- persistence or state changes.

## Open issues

- known limitations,
- deferred work,
- failing or missing tests.

## Next best task

- the single highest-value next slice,
- suggested subagent split if the next slice is parallelizable.
